# piper-tts

TTS local muito leve (roda até em Raspberry Pi) com vozes pt_BR prontas (faber, edresson, cadu, jeff e outras).

- **Tipo:** cli
- **Fonte:** https://github.com/OHF-Voice/piper1-gpl

## Uso

- O repositório original rhasspy/piper (MIT) foi **arquivado**; a continuação OHF-Voice/piper1-gpl é **GPL-3.0** (contamina projeto que embute o código; usar como programa externo evita isso).
- Vozes pt_BR em formato sherpa-onnx: https://huggingface.co/csukuangfj (repos `vits-piper-pt_BR-*`). A licença varia por voz.

## Status

Catalogado, ainda não instalado/testado.
