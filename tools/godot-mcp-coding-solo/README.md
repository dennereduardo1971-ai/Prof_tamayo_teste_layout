# godot-mcp-coding-solo

MCP MIT sem plugin: abre o editor, roda o projeto em debug e captura a saída via linha de comando.

- **Tipo:** mcp
- **Fonte:** https://github.com/Coding-Solo/godot-mcp

## Uso

Instala como uma entrada npx. Edições de cena são por arquivo (sem árvore ao vivo).
