# yt-dlp

Baixa vídeo e áudio do YouTube e de milhares de sites; útil para separar trechos de referência de voz.

- **Tipo:** cli
- **Fonte:** https://github.com/yt-dlp/yt-dlp

## Uso

- Unlicense, 196 mil estrelas, push em 27/09/2026.
- Busca sem baixar: `yt-dlp "ytsearch10:<termo>" --flat-playlist --print "%(title)s | %(channel)s | %(duration_string)s"`.
- Só áudio: `yt-dlp -x --audio-format wav <url>`.
