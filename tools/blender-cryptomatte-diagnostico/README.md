# blender-cryptomatte-diagnostico

Renderizar com os passes Cryptomatte de objeto e de material e ler, por script, a dona de cada pixel suspeito.

- **Tipo:** guia (recurso nativo)
- **Fonte:** https://docs.blender.org/manual/en/latest/render/layers/passes.html#cryptomatte

## Uso

Troca suspeita por evidência num render só (ex.: risquinho na bochecha: pele do corpo? cabelo? casco?).
