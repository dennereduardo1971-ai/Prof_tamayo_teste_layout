# fish-audio

TTS online com milhares de vozes da comunidade, inclusive personagens com dublagem PT-BR; plano grátis só para uso pessoal.

- **Tipo:** outro
- **Fonte:** https://fish.audio

## Uso

- Busca de vozes por nome do personagem (a busca por nome de dublador devolve ruído). A API pública lista modelos sem chave: `https://api.fish.audio/model?title=<nome>&language=pt&sort_by=task_count`.
- Plano grátis (out/2026): cerca de 8.000 créditos/mês (~7 min de fala), 500 caracteres por geração, sem API. A API é paga por uso.
- As vozes da comunidade podem ser removidas: baixar e guardar o áudio gerado.
- O modelo não baixa; só o MP3/WAV gerado. Não funciona offline.
- Licença: termos do serviço; o plano grátis é só para uso pessoal.
